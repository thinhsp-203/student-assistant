# Hướng dẫn Cài đặt Frontend - Trợ lý Sinh viên Thông minh

## Yêu cầu hệ thống
- Node.js (phiên bản 18 trở lên)

## Cài đặt
1. Cài đặt các thư viện phụ thuộc:
```bash
npm install
```

## Chạy ứng dụng (Môi trường phát triển)
```bash
npm run dev
```

## Xây dựng bản Production
```bash
npm run build
```
